# GridPulse experiment results

This folder is generated by `python backend/experiments.py` after the canonical pipeline runs. JSON and CSV files are the source of truth for the research presentation. The figures folder contains light-background PNG exports suitable for reports.

The Fusion GRU uses a 24-hour lookback, local country signals, global network context, and static centrality features. DCRNN uses the same engineered tensor but preserves the 12-node graph and applies forward and reverse diffusion before each recurrent update. Both models use training-only standardization and the final 168 hours per country as the chronological test horizon.

Results include dataset profiling, preprocessing evidence, feature catalog, training traces, ROC/PR curves, confusion matrices, model comparison, t-SNE hidden-state projection, permutation/ablation importance, qualitative error examples, and graph-intelligence evidence. The saved `models/` directory contains the trained checkpoints.

The graph-intelligence outputs are:

- `graph_stress_analysis.json`: latest node influence and edge resilience ranking plus the method metadata.
- `graph_stress_timeline.csv`: historical propagated stress, centrality, and warning/critical counts.
- `graph_resilience_ranking.csv`: counterfactual edge-removal impact for every canonical interconnector.
- `figures/graph_stress_propagation.png`: node stress after two-step neighboring-risk propagation.
- `figures/graph_resilience_ranking.png`: edge criticality from dynamic stress and topology impact.
- `figures/graph_stress_timeline.png`: replay-time stress and warning/critical edge counts.
- `figures/graph_node_influence.png`: node influence ranking for the saved latest snapshot.

The graph method is an explanatory screening layer. It combines utilization, endpoint risk, neighboring propagated risk, loss proxy, edge betweenness, disconnected-pair impact, and alternate shortest paths. It does not claim AC power-flow, thermal, voltage-stability, or formal N-1 certification.

The physical-loss calculation remains a distance-based proxy. Neither neural model is a dispatch controller.
