# Three-person presentation plan

This folder divides the current 36-slide GridPulse deck into three equal sections of 12 slides each.

If the final PowerPoint has different slide numbers, follow the slide titles written in each note file.

## Distribution

| Speaker | Slides | Main responsibility |
|---|---:|---|
| Person 1 | 1–12 | Problem, domain, dataset, preprocessing, features, graph, and architecture |
| Person 2 | 13–24 | Technology stack, integration, forecasting, metrics, validation, loss equations, routing, and interface |
| Person 3 | 25–36 | DCRNN research results, model comparison, feature interpretation, algorithm examples, limitations, and references |

## Suggested timing

For a 24-minute presentation, each person speaks for approximately 8 minutes. Spend about 35–45 seconds per slide and slow down for equations or graphs.

## Files

- `PERSON_1_DATA_AND_FOUNDATION.md`
- `PERSON_2_MODELS_RESULTS_AND_ROUTING.md`
- `PERSON_3_DCRNN_RESEARCH_AND_CONCLUSION.md`
- `CONTRIBUTION_MATRIX.md`

Each speaker should explain the slides in their own words rather than read every sentence. The notes include an opening, slide-by-slide speaking points, contribution statement, likely questions, and handoff line.
