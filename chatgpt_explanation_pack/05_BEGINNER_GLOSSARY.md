# Beginner glossary

| Term | Simple meaning |
|---|---|
| Node | A country or grid location in the network |
| Edge | An interconnector or power line between two nodes |
| Net flow | The overall power-flow value for a country or link after combining directions according to the dataset convention |
| Feature | An input value given to a model |
| Target | The value the model is trying to predict |
| Lookback window | How many previous hours the model reads before making a prediction |
| Forecast | An estimate of a future value |
| Baseline | A simple model used as a fair comparison |
| GRU | A neural network that remembers useful information from a sequence |
| DCRNN | A sequence model that also passes information between connected graph nodes |
| Training | Showing historical examples to a model so it can learn patterns |
| Validation | Checking choices while developing the model |
| Test set | Unseen historical data used for final evaluation |
| MAE | Average absolute prediction mistake |
| RMSE | Error metric that penalizes large mistakes more strongly |
| Precision | Of the warnings raised, how many were correct |
| Recall | Of the real warnings, how many were detected |
| F1-score | A combined balance of precision and recall |
| Headroom | Unused capacity remaining on a line |
| Utilization | How much of a line's available capacity is being used |
| Prescriptive analytics | Using predictions to recommend an action |
| Rerouting | Testing whether some flow can move through another connected path |
| Proxy | An estimate used when exact engineering measurements are unavailable |
| Walk-forward validation | Testing predictions in time order without using future data |
