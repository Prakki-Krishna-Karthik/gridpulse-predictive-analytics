# GridPulse project explanation pack

This folder contains a ready-to-use prompt and a simple upload guide for asking ChatGPT Web to explain the project to a beginner.

## Use it in five steps

1. Open ChatGPT Web.
2. Upload the project files listed in `02_UPLOAD_CHECKLIST.md`.
3. Open `01_COPY_PASTE_PROMPT.txt`.
4. Copy the entire prompt and paste it into ChatGPT.
5. Ask ChatGPT to use the actual source code and results, not assumptions.

## Important accuracy rule

The prompt tells ChatGPT to distinguish the current website forecast from the offline research models. In the current project, the website forecast uses the selected operational baseline, while Fusion GRU and DCRNN are included in the research comparison and results.
